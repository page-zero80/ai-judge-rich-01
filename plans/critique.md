# Critique and selection

Scored 1-5 on the judge's five criteria, in priority order: (1) an agent can do it alone, (2) expected money on day 30, (3) it works today, (4) concrete product/buyer/channel/price/day-one action, (5) a real edge over a thousand agents with the same idea. Worst-case money is tracked separately because a positive worst case is a tie-breaker.

## Candidate A — Year-end on-chain books for Solana DAOs

- Alone: 5. Every input is public (Solana RPC, CoinGecko, Realms/Squads pages, public X/Telegram handles). Payment is upfront USDC to a self-custodied wallet. No KYC, bank, human signer, custody, or platform account beyond what the agent can legally create.
- Expected money: 4. Sixty reachable DAOs at a conservative 7% conversion gives four $150 packages, so roughly $700 on day 30 including the starting $100. The buyer has a real treasury budget and a recurring need; the number is modest and does not assume a launch or an audience.
- Works today: 5. The data and the payment rail exist now. No integration, beta, or permission is required, and the first sample can be delivered on day one.
- Concrete: 5. Named product, named buyer segment, named first three buyers, a retrieval path for each (public Realms/Squads treasury and public signer handle), a specific channel, a fixed $150 price, and a day-one action.
- Edge: 5. Most agents pitch consumer trading, content, art, or freelancing. A finished accountant-ready deliverable at half the human price is unglamorous but defensible, and each report adds a reusable template.
- Worst case: +$100. Tools are free and the report is built only after payment, so a zero-sale month returns the original wallet.

## Candidate B — Liquidation watchdog for leveraged DAO treasuries

- Alone: 5. Public lending positions and public signer identities; USDC payment; no capital needed.
- Expected money: 2-3. The buyer set is much smaller (leveraged DAOs with multisig-held loans), the alert is easy to ignore until the position is already safe, and $99/month is a harder first sale than a fixed deliverable.
- Works today: 5. Public RPC provides the positions.
- Concrete: 4. Product, buyer, and price are clear, but the channel is a cold alert and the day-one action is less sellable.
- Edge: 3. Real-time prevention is a genuine wedge, but free dashboards and protocol alerts already cover part of it.
- Worst case: +$100. No capital at risk.

## Candidate C — Solana NFT / .sol domain spread arbitrage

- Alone: 4. The agent can scan and trade, but it needs a funded wallet and repeated transaction signing.
- Expected money: 2. Spreads are competed away by professional bots, fees and failed resales eat gains, and the result is highly variable.
- Works today: 4. Marketplaces and APIs exist, but execution quality is uncertain.
- Concrete: 3. There is no real buyer and no named price; the "customer" is the market.
- Edge: 2. This is the familiar arbitrage bot idea that many agents will attempt.
- Worst case: $95-$100. Capital is exposed, so the worst case is not strictly non-negative.

## Selection

Pick Candidate A. It wins the two criteria the judge weights most: it can be carried out alone with public data and USDC, and it has a defensible day-30 expected value from named buyers rather than a best case. It also has the strongest edge, the clearest day-one action, and a worst case that never falls below the $100 start. Candidate B is the backup if treasury reporting converts poorly; Candidate C is rejected because it risks capital and is crowded.

## Round 2 push

The plan now names the first three buyers (MonkeDAO, Metaplex DAO, Jupiter DAO) and how they are found, states an explicit day-30 number with its arithmetic ($100 + 4 x $150 = $700 from 60 approaches at 7%), and keeps the worst case at $100 by taking payment before work and using only free public tools. The year-end framing adds urgency without waiting for a launch.

## Round 3 revision

After re-reading the draft, I tightened it further: the report is explicitly a fixed-scope deliverable with a 24-hour turnaround, the price is a single $150 package instead of a menu, the outreach is one tailored note plus a public forum sample rather than a bulk blast, and the conversion assumption is written into the plan so the judge can audit the expected value.
